## Phase 1 — Compliance Program Structure

### The 7 Elements of an Effective Compliance Program

(Based on DOJ Evaluation Criteria and Federal Sentencing Guidelines)

| Element | What it requires | How we'll address it |
|---------|-----------------|---------------------|
| 1. Written standards and procedures | Policies covering each regulatory obligation | [Policy inventory] |
| 2. Compliance leadership | Senior executive or committee with compliance authority | [Named CCO/DRI] |
| 3. Training and education | Regular, role-specific, documented training | [Training program] |
| 4. Communication channels | Accessible reporting / hotline for concerns | [Mechanism] |
| 5. Monitoring and auditing | Regular testing of control effectiveness | [Audit cadence] |
| 6. Consistent enforcement | Disciplinary action for violations | [Process] |
| 7. Response and prevention | Documented response to detected problems | [Incident process] |

### Program Governance Model

```
Board / Audit Committee
    ↓ Oversight
Chief Compliance Officer (or equivalent)
    ↓ Program ownership
Compliance Committee (cross-functional: Legal, Finance, IT, HR, Operations)
    ↓ Coordination
Compliance Champions (business unit level)
    ↓ Day-to-day
All employees (first line of defense)
```

**Control types:**
- **Preventive** — stops violation before it occurs (training, approval workflows, system blocks)
- **Detective** — identifies violation after it occurs (monitoring, audits, reports)
- **Corrective** — fixes violation and prevents recurrence (remediation process, process update)

## Phase 4 — Compliance Maturity Model

### Maturity Scale (score each dimension 1–5)

| Level | Score | Description |
|-------|-------|-------------|
| Ad hoc | 1 | No formal compliance program; reactive to violations |
| Developing | 2 | Basic policies exist; inconsistently applied; limited monitoring |
| Defined | 3 | Documented program; consistent application; annual review |
| Managed | 4 | Metrics-driven; proactive monitoring; trained compliance function |
| Optimized | 5 | Continuous improvement; integrated into business processes; board visibility |

### Maturity Assessment

| Dimension | Current score | Target score | Gap | Priority actions |
|-----------|--------------|-------------|-----|-----------------|
| Written standards | /5 | /5 | | |
| Leadership and governance | /5 | /5 | | |
| Training and awareness | /5 | /5 | | |
| Monitoring and auditing | /5 | /5 | | |
| Communication channels | /5 | /5 | | |
| Enforcement consistency | /5 | /5 | | |
| Incident response | /5 | /5 | | |
| **Overall maturity** | **/35** | **/35** | | |

**Overall maturity scoring:**
- 28–35 (4–5 avg): Managed/Optimized — maintain; focus on continuous improvement
- 21–27 (3–4 avg): Defined — solidify existing program; fill gaps
- 14–20 (2–3 avg): Developing — prioritize policy formalization + training
- ≤ 13 (1–2 avg): Ad hoc — urgent: basic program build required

| Control type | Testing frequency | Method | Documentation |
|-------------|------------------|--------|---------------|

| Medium-risk, detective | Quarterly | Structured sample review | Quarterly findings memo |

### Training Matrix

| Program | Audience | Frequency | Format | Duration | Completion tracked? |

- Pre/post quiz scores: target ≥ 80% pass rate
- Behavior indicators: track related violations before/after training
- Acknowledgment: signed attestation for policies requiring annual re-read

## Phase 7 — Incident and Whistleblower Design

### Reporting Channel Options

| Channel | Anonymity | Availability | Best for |
|---------|-----------|-------------|---------|
| Internal ethics hotline (phone) | Optional | 24/7 | Employees who prefer phone |
| Anonymous web portal | Yes | 24/7 | Employees fearing retaliation |
| Direct to CCO/Legal | No | Business hours | Managers escalating concerns |
| HR confidential | Yes | Business hours | Employment-related concerns |

### Incident Response Process

```
Step 1 — Receipt: Document the report within 24 hours. Assign case ID.
Step 2 — Triage (48 hours): Is this a compliance matter or HR matter? Determine lead.
Step 3 — Preserve evidence (if potential violation): Place litigation hold if needed.
Step 4 — Investigate (5–30 days depending on complexity): Fact-finding by compliance/legal.
Step 5 — Finding: Violation confirmed / Not substantiated / Inconclusive.
Step 6 — Remediation: Disciplinary action + process fix + control update.
Step 7 — Report: Brief CCO/board if material. Document closure.
Step 8 — Root cause: Update controls to prevent recurrence.
```
