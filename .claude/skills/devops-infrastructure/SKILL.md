# DevOps / Infrastructure Skills

**8 skills across 4 phases.** Pick the one that matches where you are.

## Discover — assess current state
- `/ds-devops-infrastructure-infrastructure-audit` — Assess current infrastructure state, gaps, cost, and reliability
- `/ds-devops-infrastructure-dependency-mapping` — Map system dependencies, failure points, and blast radius

## Define — design the target state
- `/ds-devops-infrastructure-infrastructure-design` — Design the target infrastructure architecture with rationale
- `/ds-devops-infrastructure-sla-definition` — Define service level objectives, agreements, and error budgets

## Develop — build the pipeline and code
- `/ds-devops-infrastructure-ci-cd-pipeline` — Design and build the CI/CD pipeline with stages and gates
- `/ds-devops-infrastructure-infrastructure-as-code` — Write IaC (Terraform, Pulumi, CDK) for the target infrastructure

## Deliver — automate and respond
- `/ds-devops-infrastructure-deployment-automation` — Automate deployment, rollback, and blue/green strategies
- `/ds-devops-infrastructure-incident-management` — Define and run the incident response process and on-call playbook
