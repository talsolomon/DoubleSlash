# Brand Strategy
**Domain**: Brand | **Phase**: Define | **Invocation**: `/ds-brand-brand-strategy`

## What this produces
A brand strategy document with purpose, vision, values, personality, positioning, and audience definition.

## Methods
Brand purpose definition, vision and mission writing, brand values definition, brand personality spectrum, brand archetype selection, positioning statement, audience definition, brand promise articulation, brand pillars design, competitive differentiation

## FISH Guide
| Fish | Run these methods |
|---|---|
| Nemo | Purpose, 3 values, brand archetype, positioning statement |
| Tuna | Purpose, values, personality, positioning, audience |
| Salmon | Full strategy with pillars, promise, competitive differentiation |
| Willy | All methods — full brand architecture, vision/mission, stakeholder alignment |

## Execution prompt
You are running Brand Strategy for [project]. Define what the brand stands for before any visual or verbal identity work begins.

Input: company/product description, target audience, competitive landscape.
FISH classification: [Nemo/Tuna/Salmon/Willy]

Final output: brand purpose (1 sentence), 3–5 values (with descriptions), brand personality (5 attributes), positioning statement, audience definition.
