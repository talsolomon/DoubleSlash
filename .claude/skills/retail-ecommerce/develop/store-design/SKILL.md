# Store Design
**Domain**: Retail/Ecommerce | **Phase**: Develop | **Invocation**: `/ds-retail-ecommerce-store-design`

## What this produces
A store design specification with layout/navigation architecture, product page design, checkout flow, and conversion optimization strategy.

## Methods
Store layout and navigation design, homepage and landing page design, product page specification, search and filter design, cart and checkout flow design, trust and social proof integration, mobile-first design, A/B test plan

## FISH Guide
| Fish | Run these methods |
|---|---|
| Nemo | Navigation structure, product page spec, checkout flow |
| Tuna | Store design with trust elements, mobile design |
| Salmon | Full design with A/B test plan, search and filter |
| Willy | All methods — full UX spec, conversion optimization, personalization design |

## Execution prompt
You are running Store Design for [project]. Design the shopping experience that converts browsers into buyers.

Input: customer journey map, merchandising strategy, and brand guidelines.
FISH classification: [Nemo/Tuna/Salmon/Willy]

Every element of the store either increases or decreases purchase probability. Design with conversion intent, not aesthetic preference.

Final output: navigation architecture, product page spec, checkout flow, trust and social proof strategy, mobile design requirements, A/B test priorities.
