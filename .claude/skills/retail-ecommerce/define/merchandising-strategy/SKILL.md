# Merchandising Strategy
**Domain**: Retail/Ecommerce | **Phase**: Define | **Invocation**: `/ds-retail-ecommerce-merchandising-strategy`

## What this produces
A merchandising strategy with assortment architecture, display and categorization logic, inventory model, and sell-through targets.

## Methods
Assortment architecture design, category hierarchy design, hero/core/long-tail classification, display and visual merchandising design, inventory depth and width planning, sell-through rate targeting, markdown strategy, seasonal range planning

## FISH Guide
| Fish | Run these methods |
|---|---|
| Nemo | Assortment architecture, hero products, inventory approach |
| Tuna | Strategy with category hierarchy, sell-through targets |
| Salmon | Full strategy with seasonal planning, markdown strategy |
| Willy | All methods — full assortment model, inventory depth, visual merchandising |

## Execution prompt
You are running Merchandising Strategy for [project]. Define what to sell, how to organize it, and how to manage inventory.

Input: market research, customer journey map, and supplier capabilities.
FISH classification: [Nemo/Tuna/Salmon/Willy]

Assortment width without depth creates out-of-stocks. Depth without width creates boring. Balance both against inventory cost.

Final output: assortment architecture, hero/core/long-tail breakdown, category hierarchy, inventory model, sell-through targets, markdown triggers.
