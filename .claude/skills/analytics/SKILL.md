# Analytics Skills

**8 skills across 4 phases.** Pick the one that matches where you are.

## Discover — understand the data landscape
- `/ds-analytics-analytics-audit` — Assess current analytics coverage, tracking gaps, and data quality
- `/ds-analytics-data-discovery` — Explore available data sources, schemas, and their business relevance

## Define — specify what to measure
- `/ds-analytics-kpi-definition` — Define measurable KPIs with targets, baselines, and owners
- `/ds-analytics-measurement-framework` — Design the measurement architecture for a product or initiative

## Develop — build the instrumentation
- `/ds-analytics-analytics-implementation` — Build the tracking plan, event taxonomy, and data pipeline
- `/ds-analytics-dashboard-design` — Design a dashboard that answers the key questions for the audience

## Deliver — report and improve
- `/ds-analytics-reporting` — Synthesize data into a stakeholder-ready report with clear recommendations
- `/ds-analytics-data-retrospective` — Grade data quality, coverage, and analytics ROI; capture improvements
