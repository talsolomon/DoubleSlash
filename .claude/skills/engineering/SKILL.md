# Engineering Skills

**8 skills across 4 phases.** Pick the one that matches where you are.

## Discover — assess the system
- `/ds-engineering-system-audit` — Assess current system health, technical debt, and constraints
- `/ds-engineering-tech-landscape-research` — Map technology options and evaluate trade-offs for a given problem

## Define — specify before building
- `/ds-engineering-api-design` — Design the API contract, endpoints, and interface spec
- `/ds-engineering-technical-spec` — Write the technical specification for a feature or system

## Develop — design and review
- `/ds-engineering-architecture-design` — Design the system architecture with rationale and trade-offs
- `/ds-engineering-code-review` — Review code for correctness, security, performance, and quality

## Deliver — ship and recover
- `/ds-engineering-deployment-planning` — Plan the release, feature flags, rollback strategy, and runbook
- `/ds-engineering-incident-retrospective` — Run a blameless post-mortem and capture actionable learnings
