# Message Architecture
**Domain**: PR/Communications | **Phase**: Define | **Invocation**: `/ds-pr-communications-message-architecture`

## What this produces
A message architecture document with core messages, supporting proof points, audience-specific adaptations, and a message testing framework.

## Methods
Core message development, proof point identification and validation, audience message adaptation, message hierarchy design, bridging phrase development, message testing framework, competitive message differentiation, story and narrative arc design

## FISH Guide
| Fish | Run these methods |
|---|---|
| Nemo | 3 core messages, top proof points, audience variants |
| Tuna | Architecture with message hierarchy, bridging phrases |
| Salmon | Full architecture with competitive differentiation, narrative arc |
| Willy | All methods — testing framework, full proof point library, spokesperson guide |

## Execution prompt
You are running Message Architecture for [project]. Build the message system that every communication is built on.

Input: communications strategy and key business narratives.
FISH classification: [Nemo/Tuna/Salmon/Willy]

Messages that can't be remembered can't be repeated. Test every core message against: can our CEO say this in one sentence under pressure?

Final output: core messages (max 3), proof points per message, audience adaptations, bridging phrases, message testing criteria.
