### 2. Platform-Specific Adaptation

The same content must be adapted for each platform — not copy-pasted.

| Content type | Platform | Adaptation approach | Format spec |
|---|---|---|---|
| Long-form article | Website | Full article, SEO-optimized | Full text + metadata |
| Long-form article | Newsletter | 200-word summary + link | Plain text + link |
| Long-form article | LinkedIn | Key insight + 2-3 paragraphs + link | 1,300 char max before "see more" |
| Long-form article | Twitter/X | Thread: 5-7 tweets, 1 key insight per tweet | 280 char per tweet |
| Long-form article | LinkedIn Story | 3-5 slides — visual key points | Square image format |

**Platform editorial calendar** — which platform gets content in what order:
```
Day 0 (publish day): Website + Email newsletter
Day 1: LinkedIn post + Twitter thread
Day 2: Secondary social (Instagram / Facebook if applicable)
Day 7: Repost/reshare with fresh angle on LinkedIn
Day 30: Update and repost evergreen content (if still relevant)
```
