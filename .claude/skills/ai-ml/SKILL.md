# AI / ML Skills

**8 skills across 4 phases.** Pick the one that matches where you are.

## Discover — assess opportunity and data
- `/ds-ai-ml-ai-opportunity-assessment` — Identify AI/ML opportunities worth building and prioritize by impact and feasibility
- `/ds-ai-ml-data-landscape` — Map available data sources, quality, coverage, and pipeline gaps

## Define — frame the problem
- `/ds-ai-ml-ml-problem-framing` — Frame the ML problem type, success metric, baseline, and evaluation criteria
- `/ds-ai-ml-data-requirements` — Specify what data is needed, at what quality, and how to acquire it

## Develop — build the model
- `/ds-ai-ml-model-design` — Design the model architecture, training approach, and evaluation plan
- `/ds-ai-ml-prompt-engineering` — Design, test, and optimize prompts for LLM-based systems

## Deliver — deploy and learn
- `/ds-ai-ml-ai-deployment` — Plan and execute model deployment, monitoring, and rollback
- `/ds-ai-ml-model-retrospective` — Grade model performance against baselines and capture iteration priorities
