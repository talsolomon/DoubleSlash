# Product Skills

**8 skills across 4 phases.** Pick the one that matches where you are.

## Discover — understand before you build
- `/ds-product-customer-discovery` — Surface real user problems through interviews, JTBD, and empathy mapping
- `/ds-product-opportunity-landscape` — Map and size the opportunity space (TAM/SAM/SOM, whitespace, early adopters)

## Define — frame the problem and requirements
- `/ds-product-problem-framing` — Frame the problem with HMW, POV, north star metric, and RICE score
- `/ds-product-requirements-definition` — Write the PRD, user story map, and acceptance criteria

## Develop — design the solution
- `/ds-product-solution-ideation` — Generate and rank solution concepts with trade-off analysis
- `/ds-product-roadmap-design` — Build the NOW/NEXT/LATER roadmap with OKRs and dependency map

## Deliver — ship and measure
- `/ds-product-launch-planning` — Build the GTM plan, rollout strategy, and success metrics
- `/ds-product-product-retrospective` — Grade OKRs, capture lessons learned, kill/continue/pivot
