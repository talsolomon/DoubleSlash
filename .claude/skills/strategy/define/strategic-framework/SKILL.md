# Strategic Framework
**Domain**: Strategy | **Phase**: Define | **Invocation**: `/ds-strategy-strategic-framework`

## What this produces
A strategic framework with vision, mission, 3–5 strategic priorities, key bets, and success measures.

## Methods
Vision and mission articulation, strategic priority setting, strategic bet definition, OKR framework design, theory of change, balanced scorecard, strategic choice cascade (Roger Martin), where-to-play/how-to-win framework

## FISH Guide
| Fish | Run these methods |
|---|---|
| Nemo | Vision, mission, top 3 priorities |
| Tuna | Framework with priorities, bets, OKRs |
| Salmon | Full framework with choice cascade, theory of change |
| Willy | All methods — balanced scorecard, full OKR cascade, stakeholder alignment |

## Execution prompt
You are running Strategic Framework for [project]. Build the strategic architecture that guides decisions for the next planning horizon.

Input: strategic landscape, competitive analysis, and current state assessment.
FISH classification: [Nemo/Tuna/Salmon/Willy]

Final output: vision (1 sentence), mission (2 sentences), 3–5 strategic priorities with rationale each, top 3 strategic bets, OKRs per priority.
