# User Research
**Domain**: UX Design | **Phase**: Discover | **Invocation**: `/ds-ux-design-user-research`

## What this produces
A research synthesis with key behavioral patterns, unmet needs, mental models, and design implications.

## Methods
Contextual inquiry, semi-structured interview, diary study, behavioral observation, card sorting, tree testing, guerrilla research, co-discovery session, screen recording analysis, support ticket analysis, heatmap and session replay review, accessibility audit

## FISH Guide
| Fish | Run these methods |
|---|---|
| Nemo | Semi-structured interview guide (5 users), key findings synthesis |
| Tuna | Interviews, behavioral observation, synthesis into patterns |
| Salmon | Contextual inquiry, card sorting, diary study design, pattern synthesis |
| Willy | All methods — full research program with multiple methodologies |

## Execution prompt
You are running User Research for [project]. Surface real behavioral patterns and unmet needs before any design work begins.

Input: the design problem or feature area being researched.
FISH classification: [Nemo/Tuna/Salmon/Willy]

For each method: produce the research instrument (guide, task list, etc.), then synthesize findings.

Final output: top 5 behavioral patterns with evidence, top 3 unmet needs, mental model description, design implications.
