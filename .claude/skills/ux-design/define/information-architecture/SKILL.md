# Information Architecture
**Domain**: UX Design | **Phase**: Define | **Invocation**: `/ds-ux-design-information-architecture`

## What this produces
An information architecture document with site/app structure, navigation hierarchy, content taxonomy, and findability analysis.

## Methods
Card sorting (open/closed), tree testing, site map design, navigation hierarchy design, content taxonomy, mental model mapping, findability analysis, label testing, wayfinding design, search and filter architecture

## FISH Guide
| Fish | Run these methods |
|---|---|
| Nemo | Site map sketch, navigation hierarchy, top-level labels |
| Tuna | Site map, navigation design, card sort analysis |
| Salmon | Full IA with taxonomy, tree testing, findability analysis |
| Willy | All methods — label testing, wayfinding design, search architecture |

## Execution prompt
You are running Information Architecture for [project]. Define the structure and navigation before any wireframing begins.

Input: content inventory, user research, and product scope.
FISH classification: [Nemo/Tuna/Salmon/Willy]

Start with user mental models, then map content to structure, then design navigation.

Final output: site/app map with hierarchy, navigation labels, taxonomy decisions, findability assessment.
