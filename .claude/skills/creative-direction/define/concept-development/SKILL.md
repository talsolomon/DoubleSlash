# Concept Development
**Domain**: Creative Direction | **Phase**: Define | **Invocation**: `/ds-creative-direction-concept-development`

## What this produces
2–3 distinct creative concepts, each with a core idea, rationale, execution approach, and visual/verbal direction.

## Methods
Creative concepting, concept territory mapping, big idea development, tagline exploration, visual concept description, copy concept development, concept evaluation matrix, stakeholder presentation framing

## FISH Guide
| Fish | Run these methods |
|---|---|
| Nemo | 2 concepts with core idea and visual direction |
| Tuna | 3 concepts with rationale, execution approach, tagline |
| Salmon | Full concepts with evaluation matrix, presentation framing |
| Willy | All methods — territory mapping, concept iterations, full presentation |

## Execution prompt
You are running Concept Development for [project]. Generate distinct creative directions that answer the brief differently.

Input: creative brief and inspiration map.
FISH classification: [Nemo/Tuna/Salmon/Willy]

For each concept: name it, state the core idea (1 sentence), describe the visual direction, write sample copy, explain why it works against the brief.

Final output: 2–3 named concepts each with idea, visual direction, sample copy, and brief rationale.
