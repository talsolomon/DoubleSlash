# Creative Brief
**Domain**: Creative Direction | **Phase**: Define | **Invocation**: `/ds-creative-direction-creative-brief`

## What this produces
A one-page creative brief with objective, audience, message hierarchy, tone, deliverables, constraints, references, success criteria, and approval process.

## FISH Guide
| Fish | Depth |
|---|---|
| Nemo | Objective, audience, tone descriptors, top deliverable |
| Tuna | Full brief: objective, audience, tone, deliverables, constraints, references |
| Salmon | Brief with message hierarchy, success criteria, approval process |
| Willy | All methods — stakeholder sign-off checklist, revision protocol, legal/compliance review flags |

---

## Execution Prompt

You are writing a Creative Brief for [project]. This document enables a creative team to produce the right work on the first attempt without back-and-forth.

**Input**: project goal, target audience, brand guidelines, timeline, budget range, known constraints.

---

### Creative Brief

**Project**: [Name]
**Date**: [Date]
**Prepared by**: [Name/Role]
**Due**: [Final delivery date]
**Budget**: [Range or TBD]

---

#### 1. Objective

One sentence. Complete this: *"This work will [desired action] for [audience] so that [business outcome]."*

> Example: "This work will drive trial sign-ups for [product] from [audience segment] so that we hit [X] new users by [date]."

**Success metric**: [Primary KPI and target]
**Secondary metrics**: [2-3 supporting metrics]

---

#### 2. Audience

**Primary audience**: [Persona name or segment]
- Demographics: [Age range, location, role/situation if B2B]
- Psychographics: [Motivations, fears, values, identity]
- Current relationship with brand: [Unaware / aware / considering / customer]
- What they believe now: [The assumption we need to shift]
- What we want them to believe after seeing this: [The new belief]

**Secondary audience** (if applicable): [Who else will see this and what matters to them]

---

#### 3. Message Hierarchy

| Level | Content |
|---|---|
| Single Minded Proposition | [The one thing this work must communicate — one sentence] |
| Core Message | [The main message in plain language] |
| Supporting Messages | [2-3 reasons to believe / proof points] |
| Emotional Undercurrent | [What should the audience feel — not think] |

**What this work is NOT trying to say**: [2-3 explicit exclusions — prevents scope creep]

---

#### 4. Tone and Personality

**5 tone descriptors** (pick words that create a creative fence, not generic descriptors):
1. [e.g., Wry — not sarcastic]
2. [e.g., Direct — not blunt]
3. [e.g., Warm — not saccharine]
4. [e.g., Ambitious — not arrogant]
5. [e.g., Grounded — not boring]

**Tone reference**: [Brand/campaign the tone should feel like — explain why]
**Tone anti-reference**: [Brand/campaign the tone must NOT resemble — explain why]

---

| Asset | Format/Specs | Quantity | Due Date | Notes |

| [Social posts] | [Platform, ratio, duration if video] | | | |
| [Email] | [Width, plain text backup required?] | | | |
| [Landing page copy] | [Section structure] | | | |

**Primary deliverable** (if the team can only nail one thing, it's this): [Asset name]

---

#### 6. Hard Constraints

These are non-negotiable — do not route creative through them.

- **Brand**: [Specific logo placement, color restrictions, font rules from guidelines]
- **Legal/Regulatory**: [Claims that require substantiation, disclaimers required, prohibited language]
- **Budget**: [What cannot be produced due to cost — e.g., no live action video]
- **Timeline**: [Immovable dates — e.g., campaign must launch before X]
- **Technical**: [Platform specs, file size limits, accessibility requirements]
