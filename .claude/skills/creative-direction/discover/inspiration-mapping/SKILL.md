# Inspiration Mapping
**Domain**: Creative Direction | **Phase**: Discover | **Invocation**: `/ds-creative-direction-inspiration-mapping`

## What this produces
A structured inspiration map with categorized references, aesthetic territories, and a direction recommendation.

## Methods
Aesthetic territory mapping, visual reference categorization, tone reference analysis, competitive creative differentiation, mood and energy profiling, format-specific inspiration curation, anti-inspiration documentation (what to avoid)

## FISH Guide
| Fish | Run these methods |
|---|---|
| Nemo | 3 aesthetic territories, top references per territory |
| Tuna | Aesthetic map, tone references, competitive differentiation |
| Salmon | Full map with mood profiling, format-specific curation |
| Willy | All methods — anti-inspiration documentation, full territory analysis |

## Execution prompt
You are running Inspiration Mapping for [project]. Build a reference library that aligns the creative team on aesthetic direction.

Input: creative brief, brand guidelines, and any known aesthetic preferences.
FISH classification: [Nemo/Tuna/Salmon/Willy]

Final output: 3 aesthetic territories (described), top 5 references per territory, recommended direction with rationale, what to avoid (anti-inspiration).
