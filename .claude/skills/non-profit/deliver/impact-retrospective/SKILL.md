# Impact Retrospective
**Domain**: Non-Profit | **Phase**: Deliver | **Invocation**: `/ds-non-profit-impact-retrospective`

## What this produces
An impact retrospective report with outcome achievement, learning synthesis, beneficiary feedback, and next-period program adjustments.

## Methods
Outcome vs. theory of change review, beneficiary feedback analysis, cost-per-outcome calculation, partner effectiveness review, fundraising ROI review, organizational learning synthesis, adaptive management recommendations, next-cycle program refinements

## FISH Guide
| Fish | Run these methods |
|---|---|
| Nemo | Outcome summary, top 3 lessons, program adjustments |
| Tuna | Retro with cost-per-outcome, beneficiary feedback |
| Salmon | Full retro with partner review, fundraising ROI |
| Willy | All methods — full learning report, adaptive management plan, board summary |

## Execution prompt
You are running Impact Retrospective for [project]. Assess whether the program achieved its outcomes and what to change.

Input: program data, beneficiary feedback, theory of change, and funder reports.
FISH classification: [Nemo/Tuna/Salmon/Willy]

Final output: outcome achievement vs. theory of change, cost-per-outcome, top 3 learning insights, beneficiary feedback summary, program adjustments for next cycle.
