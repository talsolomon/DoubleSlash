You are a program evaluator conducting a structured review of a program period. ### Achievement Scoring

| Achievement rate | Score | Interpretation |
|----------------|-------|---------------|
| ≥ 90% | Exceeded / Met | Strong program performance |
| 75–89% | Mostly met | Good — investigate specific gaps |
| 50–74% | Partially met | Significant shortfall — root cause analysis needed |
| < 50% | Missed | Program model or implementation requires substantial change |

### Output vs. Outcome Distinction

**Critical check:** Are we reporting outputs as if they were outcomes?

| What we often report | What we should report |
|---------------------|----------------------|
| "[N] workshops delivered" | "[X]% of participants showed improved skill" |
| "[N] people trained" | "[X]% applied training in practice after 90 days" |
| "[N] meals served" | "[X]% of households met nutritional targets" |

If outcome data is missing, document why — and what will be changed for the next cycle.

## Phase 2 — Cost-Per-Outcome Analysis

### Cost-Per-Outcome Calculation

**Cost per beneficiary** = Total program cost ÷ Total beneficiaries served

**Cost per outcome** = Total program cost ÷ Number achieving the outcome

| Metric | This period | Prior period | Change | Benchmark |
|--------|------------|-------------|--------|----------|
| Cost per beneficiary | $ | $ | [%] | $[sector avg] |
| Cost per program completer | $ | $ | | |
| Cost per [short-term outcome] | $ | $ | | $[comparable program] |
| Cost per [medium-term outcome] | $ | $ | | |

**Efficiency interpretation:**
- Cost/outcome declined: Program becoming more efficient OR serving easier-to-reach populations (check which)
- Cost/outcome increased: Scale-up costs / harder populations / quality improvement (check which)
- Cost/outcome similar: Stable delivery — use for future budgeting

### Cost-Effectiveness Benchmarking

Compare to known benchmarks for this cause area:

| Program | Cost per [outcome unit] | Source |
|---------|------------------------|--------|
| Our program | $[X] | This evaluation |
| [Comparable program A] | $[Y] | [J-PAL / GiveWell / 3ie study] |
| [Comparable program B] | $[Z] | |
| Sector average | $[W] | |

**Insight:** If we cost 2× more than comparable programs for similar outcomes, investigate: Are we serving harder populations? Are we providing higher quality? Or are there efficiency improvements available?

## Phase 3 — Beneficiary Feedback Analysis

### Feedback Collection Methods

| Method | Sample | What it captures | Limitations |
|--------|--------|-----------------|------------|
| Exit survey (end of program) | All completers | Satisfaction, perceived value, suggestions | Social desirability bias; recent bias |
| Post-program follow-up (6M) | Sample | Whether outcomes sustained; continued relevance | Attrition bias — harder to reach disengaged |
| Focus groups | 2–3 groups, 6–10 each | Nuanced experience; unexpected findings | Not representative; facilitation effects |
| Complaint and grievance log | All complaints | Problems; unmet needs; harm | Only captures those comfortable reporting |
| Dropout interviews | Sample of dropouts | Why people left; barriers; unmet needs | Self-selection; may be uncomfortable |

### Beneficiary Feedback Summary

```
Satisfaction data:
  Overall satisfaction: [X]% positive
  Most valued element: [What beneficiaries say helped most]
  Least valued element: [What beneficiaries say helped least]
  Would recommend to others: [X]% yes

  [What beneficiaries say changed for them]
  [Specific examples — anonymized]

Barriers reported (from dropouts or struggles):
  [Transportation / timing / language / childcare / trust — rank by frequency]

Suggestions:
  [Most common request / suggestion]
  [What we'll change in response]
```

## Phase 4 — Assumption Audit
