# Program Launch
**Domain**: Non-Profit | **Phase**: Deliver | **Invocation**: `/ds-non-profit-program-launch`

## What this produces
A program launch plan with beneficiary onboarding, partner activation, community communications, and first-month monitoring plan.

## Methods
Launch event and communications design, beneficiary recruitment and onboarding, partner activation plan, media and advocacy outreach, funder reporting design, first-month monitoring, community feedback mechanism, soft launch and pilot approach

## FISH Guide
| Fish | Run these methods |
|---|---|
| Nemo | Launch checklist, communications plan, first-month monitor |
| Tuna | Launch plan with beneficiary onboarding, partner activation |
| Salmon | Full plan with media outreach, funder reporting |
| Willy | All methods — community engagement, soft launch design, full comms |

## Execution prompt
You are running Program Launch for [project]. Launch the program in a way that builds community trust and demonstrates early impact.

Input: program operations plan and stakeholder map.
FISH classification: [Nemo/Tuna/Salmon/Willy]

A successful launch generates evidence, not just attention. Build in monitoring from day one.

Final output: launch readiness checklist, communications plan, beneficiary onboarding sequence, first-month monitoring plan, funder update template.
