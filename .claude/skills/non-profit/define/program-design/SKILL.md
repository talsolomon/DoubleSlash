# Program Design
**Domain**: Non-Profit | **Phase**: Define | **Invocation**: `/ds-non-profit-program-design`

## What this produces
A program design document with activities, delivery model, beneficiary journey, partnerships, and resource requirements.

## Methods
Activity and intervention design, delivery model selection, beneficiary journey mapping, partnership model design, staff and volunteer role design, budget estimation, pilot design, safeguarding and ethics review

## FISH Guide
| Fish | Run these methods |
|---|---|
| Nemo | Activities, delivery model, resource estimate |
| Tuna | Program design with beneficiary journey, partnerships |
| Salmon | Full design with budget, pilot plan, ethics review |
| Willy | All methods — full program manual, safeguarding plan, partnership agreements |

## Execution prompt
You are running Program Design for [project]. Design the program that turns the theory of change into action.

Input: theory of change, beneficiary needs, and organizational capacity.
FISH classification: [Nemo/Tuna/Salmon/Willy]

Design around what beneficiaries actually experience, not what staff find convenient to deliver.

Final output: activity design, delivery model, beneficiary journey, partnership requirements, resource needs, pilot plan.
