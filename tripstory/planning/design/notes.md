# TripStory — Design Notes

_Placeholder. Design comes late (Phase 4), because the app shell is the smallest piece. Captured here so we don't lose early instincts._

## Experience principles
- **Audio-first.** The product is heard, not looked at. The screen is a remote control, not the show.
- **Warm companion, not a kiosk.** It greets you, rides with you, never lectures.
- **Zero-driver-distraction.** The driving parent should barely touch the phone. Voice + minimal glanceable UI.
- **Kid-legible for 8-12.** When there is a screen moment (trivia), it must be readable and playful for that age.

## Early UI surfaces (Phase 4, not now)
- Welcome / start-the-drive
- Now playing + what's around
- Family profile + memory ("what we've learned")
- Trivia moment
- Paywall (after the free story)

## Open
- Do kids interact by voice, by tapping, or only listen while the parent controls? Affects everything.
