Two Modes of Operation — Step by Step
Mode A · Keyboard
// Desktop
Press // from anywhere → Pill → Kanban
  1. Press // keyboard shortcut (system-wide)
    Works from any app, any window — DS intercepts at OS level
  2. DS Pill lights up in the menu bar
    Visual confirmation that // was intercepted
  3. Kanban opens — all projects visible
    Pulled from shared memory; Node Map embedded per project card
  4. No projects? → Start New Project
    Names the project, selects AI default (Claude), DS opens it automatically
  5. DS Splash runs: "// is ON"
    Project Intake Protocol fires: FISH → Node Map seeded → Kanban seeded → first move named
  6. Projects exist? → Select project → select task
    Task brief + project memory injected into AI context automatically
  7. Task runs in AI; output → memory → Kanban updated
    Zero admin. State captured automatically. Node Map adds a node.
Mode B · In-Agent
/ Agent
DS names the next move. User confirms. Skill runs.
  1. Session opens in Claude, GPT, or any connected agent
    DS is already present — no invocation needed
  2. DS reads full project state
    Node Map · Kanban · memory · decisions · project brief · constraints
  3. DS names one next move: "[Phase] → [What]. [Why now]. Ready?"
    Not a menu — one specific action. DS owns the agenda.
  4. User confirms → skill runs with full project context
    User types "go" or any confirmation. DS executes immediately.
  5. Output rendered inline — formatted, cited, ready to act on
    Skill output follows the method's expected format (brief, PRD, analysis, etc.)
  6. Memory updated → Kanban + Node Map updated automatically
    Zero admin. Phase advances when completion criteria are met.
  7. DS names the next move in the current phase
    User can type / at any point to pick a different skill instead — escape hatch, not the default.
Open Questions — Blocking
OQ-01 · Architecture
How does // technically intercept at the OS level across different apps? CGEventTap, Accessibility API, or hotkey approach?
OQ-02 · Naming
The product is named Duble//Slash but the trigger inside agents is a single /. Does the name still hold?
OQ-03 · Install
ChatGPT and cloud-only tools have no local root folder. What's the install strategy for AI tools that aren't locally installed?
OQ-04 · Skills Picker
How does the / skills picker surface thousands of skills without overwhelming the user? Smart defaults by role? Onboarding filter?
OQ-05 · Loop Config
What does setting a loop look like for a non-technical user? Visual scheduler? Natural language?
