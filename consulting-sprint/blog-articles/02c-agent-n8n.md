## n8n: זה לא "עוד כלי no-code", זה הרבה יותר מזה

> **n8n** — פלטפורמת אוטומציה ויזואלית שמאפשרת לחבר בין שירותים, לוגיקה, ו-AI agents בלי לכתוב קוד גרידא. כל "block" עושה דבר אחד, ואתם/ן מחברות/ים אותם בקנבס.

אם בחלק הקודם בנינו אייג׳נט עם Claude Code בטרמינל, זה היה כמו לנהוג במכונית מירוץ. n8n היא סימולטור נהיגה עם לוח מחוונים ויזואלי. אותו מנוע, הרבה פחות חיכוך.

המודל המנטלי: במקום לכתוב קוד שאומר "כשיקרה X, עשה Y, ואז Z", אתם/ן מגררות/ים בלוקים לקנבס ומחברות/ים אותם בקווים. כל בלוק (node) עושה דבר אחד בלבד. Trigger מפעיל. HTTP Request שולח בקשה. AI Agent חושב. Gmail שולח מייל. השרשרת הזאת היא ה-workflow.

מה שמייחד את n8n על פני Zapier או Make: יש לה AI Agent node מובנה. לא רק "קרא ל-ChatGPT ותחזיר תשובה", אלא לולאת Plan, Act, Observe מלאה שפועלת בדיוק כמו מה שכתבנו ב-Claude Code בחלק הקודם. ההבדל הוא שאתם/ן רואות/ים אותה קורית בזמן אמת, node אחר node, בלי להסתכל על טרמינל.

```
עובדה חביבה: n8n היא open-source ויש לה מעל 400 integrations מובנות.
Zapier, לשם השוואה, עולה פי 5-10 יותר עבור אותו נפח אוטומציות.
```

## ההחלטה הראשונה: Cloud או Self-Hosted

לפני שנוגעות/ים במקלדת, יש החלטה אחת לקבל.

**n8n.cloud** היא הגרסה המנוהלת. נרשמות/ים, נכנסות/ים, מתחילות/ים לבנות. אין התקנה, אין שרת. הטריאל בחינם ל-14 יום, ואחרי זה מתחיל ממחיר של כ-20 דולר בחודש לשימוש אישי. בשביל המדריך הזה, זה מה שנשתמש בו.

**Self-hosted** אומר שמורידות/ים את n8n ומריצות/ים אותה על המחשב או על שרת קטן בענן. הקוד פתוח, ה-community edition חינמית לגמרי. אם עובדות/ים עם נתונים עסקיים רגישים, זו הדרך הנכונה. שרת של DigitalOcean עולה כ-6 דולר בחודש.

תכלס: מתחילות/ים ב-cloud. אם יצרתם/ן workflows שהם production-worthy, עוברות/ים ל-self-hosted.

## Node ראשון: ה-Trigger שמפעיל הכל

> **Trigger** — ה-node הראשון בכל workflow. מגדיר מה גורם לאוטומציה להתחיל לרוץ.

שלושה סוגי triggers עיקריים:

**Manual Trigger:** כבר מחכה בקנבס. לוחצות/ים "Test workflow" ו-n8n מריצה עכשיו. פרפקט לפיתוח.

**Schedule Trigger:** מריץ אוטומטית בזמן קבוע. "כל יום ב-8 בבוקר" אומר Schedule Trigger עם cron expression `0 8 * * *`. אם זה נשמע מפחיד, יש UI ויזואלי שבונה את ה-cron בשבילכן/ם. לוחצות/ים "Every Day" ומגדירות/ים שעה.

**Webhook Trigger:** מחכה לאות מחוץ. לשימוש מתקדם יותר.

לצורך המדריך, משאירות/ים את ה-Manual Trigger. עוברות/ים ל-Schedule Trigger כשרוצות/ים לעבוד בפרודקשן.

## Node שני: ה-AI Agent, הלב

ה-AI Agent node מופיע בקנבס ולינק בינו לבין ה-trigger נוצר אוטומטית. לוחצות/ים עליו לפתוח את ה-configuration panel.

1. קרא את 10 המיילים האחרונים מ-Gmail (אל תקרא ספאם).

- אל תמחק כלום.

## Node שלישי: הכלים שנותנים לאייג׳נט ידיים

ה-AI Agent node לבד יכול לחשוב. הוא לא יכול לעשות. הכלים (tools) נותנים לו יכולת פעולה.

> **Tool Node** — node שמחובר ל-AI Agent דרך חיבור מיוחד מסוג "Tools". מייצג יכולת: לשלוח מייל, לקרוא גיליון, לבצע HTTP request.

**HTTP Request:** מסוגל לקרוא לכל API בעולם.

**Gmail:** קורא ושולח מיילים. דורש OAuth connection עם גוגל. כשמוסיפות/ים אותו, n8n מנחה להתחבר דרך חשבון הגוגל. תהליך של כ-3 דקות.

**Google Sheets:** קורא וכותב נתונים. גדול לזיכרון חיצוני ולוגים.

**Slack:** שולח הודעות לערוצים.

בשביל Morning Briefing: מוסיפות/ים Gmail Tool ו-Google Sheets Tool. כל אחד מחובר ל-AI Agent דרך "Tools Connection", לא דרך חיבור רגיל. לוחצות/ים על הנקודה בתחתית ה-AI Agent node (לא מהצד) כדי לפתוח את ה-Tools port. משם גוררות/ים את החיבור לכל Tool node.

## Memory Node: כי אייג׳נט שלא זוכר כלום הוא בעצם הזדמנות לכאב

בלי זיכרון, כל ריצה מתחילה מאפס. אייג׳נט שלא זוכר מה עשה אתמול יסכם את אותם מיילים שוב ושוב.

> **Window Buffer Memory** — node שמחבר ל-AI Agent ושומר את ה-context של השיחה הפנימית בתוך ריצה אחת.

מוסיפות/ים: לוחצות/ים +, מחפשות/ים "Window Buffer Memory". חיבור דרך port ה-Memory של ה-AI Agent.

**Session ID:** מחרוזת קבועה: `"morning-agent-v1"`. מבטיח שתמיד ייטען אותו context.

**Window Size:** 20. שומר 20 הודעות אחרונות.

**לזיכרון ארוך-טווח בין ריצות:** Google Sheets. בסוף כל ריצה, כותבות/ים שורה עם סיכום מה נעשה. בתחילת הריצה הבאה, קוראות/ים את 5 השורות האחרונות ומכניסות/ים אותן ל-System Prompt כ-context לפני שהאייג׳נט מתחיל לעבוד.

```
עובדה חביבה: 90% מה-agent failures בפרודקשן קורות כי האייג׳נט לא ידע
מה עשה בריצה הקודמת ועשה אותו דבר שוב.
```

## חיבור הכל: ה-Workflow המלא

כך נראה ה-workflow אחרי שסיימנו:

```
[Manual Trigger]
       |
       v
[AI Agent] <-- [Gmail Tool]
   ^   ^        [Google Sheets Tool]
   |   |
   |   +-- [Window Buffer Memory]
   |
   +-- [Google Sheets Tool (זיכרון ארוך-טווח)]
```

**איך לחבר nodes:** לוחצות/ים על הנקודה בצד ימין של node אחד. גוררות/ים לנקודה בצד שמאל של ה-node הבא.

**חיבור Tools:** ה-AI Agent node מיוחד. יש לו ports שונים: Main, Tools, Memory. וודאו שה-Tool nodes מחוברים לפורט הנכון. n8n צובעת אותם בצבעים שונים.
