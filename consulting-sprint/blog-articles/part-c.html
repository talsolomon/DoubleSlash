בנה אייג׳נט אחד: חלק ג׳ מתוך שלושה

n8n, האוטומציה שרצה לבד — בלי שתהיה שם

עד כאן, ב-Claude Desktop, בנינו אייג׳נט שמכיר אתכם/ן, זוכר הוראות, וניגש לקבצים. הוא מעולה. יש לו רק מגבלה אחת: הוא מחכה לכם/ן.

אתם/ן פותחים, אתם/ן כותבים "תריץ", אתם/ן שם. ברגע שתצאו, הוא ישן. זה לא אוטומציה. זה כלי מאוד חכם עם קליק ידני.

אייג׳נט אמיתי רץ לבד.

n8n: מה זה ולמה בחרנו בזה

n8n: פלטפורמת אוטומציה ויזואלית שמאפשרת לחבר בין שירותים ולהריץ AI agents על לוח זמנים, בלי לכתוב קוד. עובד בדפדפן, אין מה להתקין.

אם Claude Desktop הוא שותף/ה שעובד/ת לידכם/ן כשאתם/ן שם, n8n הוא עובד/ת שמגיע/ה לעבודה לבד בכל בוקר ב-8:00 ושולח/ת לכם/ן דוח עד שתגיעו.

המנגנון הוא workflow: שרשרת של steps שמתחילת ב-trigger (מה מפעיל) ועוברת דרך actions (מה עושים). כל step הוא "node" ויזואלי על קנבס. מחברות/ים אותם בקווים.

n8n בחרנו כי:

  • עובד בדפדפן לגמרי, אין התקנה
  • יש בו AI Agent node מובנה עם תמיכה ב-Claude
  • יש בו מעל 400 integrations מוכנות
  • הגרסה ה-cloud בחינם לטריאל של 14 יום
  • open-source — אם רוצות/ים self-hosted, חינמי לגמרי
עובדה חביבה: n8n מריצה מעל 100 מיליון workflow executions בחודש.
זה לא כלי ניסיוני — זה infra שארגונים גדולים מסתמכים עליו.

הקנבס: מה רואים

לוחצות/ים "New workflow". נפתח קנבס ריק עם node אחד: "When clicking Test workflow". זהו ה-trigger הידני לטסטינג.

📸 צלם/י n8n Canvas ריק — node יחיד "When clicking Test workflow" במרכז הקנבס. כפתור "+" מימינו מוכן לחיבור node הבא

לפני שממשיכות/ים, שנו את שם ה-workflow. לוחצות/ים על "My workflow" בראש, ורושמות/ים "Morning Briefing Agent".

כל workflow מורכב מ:

  • Trigger: מה מפעיל. Manual (ידני לטסטינג), Schedule (לוח זמנים), Webhook (אות מחוץ).
  • Nodes: כל פעולה שה-workflow מבצע. כל node עושה דבר אחד.
  • Connections: הקווים שמחברים node ל-node. הם קובעים את הסדר.

Node ראשון: ה-AI Agent

לוחצות/ים על + מימין ל-trigger node. נפתח חיפוש. כותבות/ים "AI Agent". לוחצות/ים.

📸 צלם/י n8n — חלון חיפוש nodes פתוח עם "AI Agent" בחיפוש. ה-node "AI Agent" מסומן בתוצאות, עם האייקון שלו

ה-AI Agent node נוסף לקנבס ומחובר אוטומטית ל-trigger. לוחצות/ים עליו לפתוח את ה-configuration panel בצד ימין.

📸 צלם/י n8n — AI Agent node על הקנבס, configuration panel פתוח בצד ימין. גלויים: שדה "System Message", dropdown ל-Model, ו-Max Iterations

System Message: זה ה"תדריך" של האייג׳נט. מה הוא עושה, מה הגבולות, מה הפורמט של התוצאה. מדביקות/ים:

אתה אייג׳נט הסיכום הבוקרי.

כל פעם שמפעילים אותך:
1. קרא את 10 המיילים האחרונים מ-Gmail שאינם ספאם
2. לכל מייל שדורש תשובה, כתוב: נושא + פעולה נדרשת + עד מתי
3. שמור את הרשימה ב-Google Sheets בגיליון "Daily Briefing", עמודה לתאריך
4. מיילים לידיעה בלבד — סכם בשורה אחת, ללא פעולה

כללים קשיחים:
- אל תשלח שום מייל בלי אישור מפורש ממני
- אל תמחק שום מייל
- אם מייל לא ברור, כתוב "לא ברור" ועבור הלאה
📸 צלם/י n8n — AI Agent configuration panel עם System Message מלא כמו בדוגמה. גלוי הטקסט בשדה, ה-node בקנבס ברקע

Model: לוחצות/ים "+ Add credential", בוחרות/ים "Anthropic Claude".

כאן נכנס ה-API key. זה הדבר היחיד שדורש קצת עבודה, אבל זה פשוט:

איך מקבלים API key מ-Anthropic:

  • הולכות/ים ל-platform.claude.com
  • נרשמות/ים (שימו לב: זה שונה מ-claude.ai — זה ה-developer platform)
  • בסיידבר: "API Keys"
  • "Create Key", נותנות/ים שם
  • מעתיקות/ים מיד — מוצג רק פעם אחת
📸 צלם/י platform.claude.com — עמוד "API Keys" מחובר. גלוי כפתור "Create Key" וה-interface של ניהול מפתחות. לא המסך הראשי, ספציפית עמוד API Keys
📸 צלם/י n8n — Anthropic credential dialog פתוח: שדה "API Key" ריק ומחכה להדבקה. כפתור "Save" בתחתית

מכניסות/ים את ה-key, לוחצות/ים Save. עכשיו n8n יכול לדבר עם Claude.

Max Iterations: שנו ל-10. זה מגביל שהאייג׳נט לא יריץ יותר מ-10 צעדים בריצה אחת.

הוספת כלים: מה האייג׳נט יכול לעשות

האייג׳נט בלי כלים יכול לחשוב אבל לא לעשות. מוסיפות/ים כלים דרך + ובחירת tool nodes.

Gmail Tool:

לוחצות/ים על + מתחת ל-AI Agent node (לא מהצד, מהתחתית — זה ה-Tools port).

📸 צלם/י n8n — AI Agent node עם שלושה ports גלויים: Input (ימין), Output (שמאל), ו-Tools (תחתית). חץ יוצא מה-Tools port כלפי מטה

מחפשות/ים "Gmail". מוסיפות/ים. נפתח חלון התחברות עם Google. מתחברות/ים לחשבון ה-Gmail שלכם/ן.

📸 צלם/י n8n — Gmail node מחובר ל-Tools port של AI Agent. Google OAuth popup פתוח עם "Allow access to Gmail"

Google Sheets Tool:

מוסיפות/ים tool node נוסף: "Google Sheets". מתחברות/ים לאותו חשבון Google. מגדירות/ים את ה-spreadsheet שאליו הסיכום ייכתב.

📸 צלם/י n8n — Google Sheets node מחובר. Configuration panel פתוח: שדה Spreadsheet ID מלא, Sheet Name "Daily Briefing"
סרטון: Building an AI Agent with n8n https://www.youtube.com/watch?v=GuaKeDS6UKU

Memory Node: כי אייג׳נט שלא זוכר זה סיזיפי

בלי זיכרון, כל ריצה מתחילה מאפס. האייג׳נט לא יודע מה סיכם אתמול, לא יכול להגיד "חדש מאתמול", יחזור על אותו עבודה שוב ושוב.

מוסיפות/ים "Simple Memory" node ומחברות/ים אותו ל-Memory port של ה-AI Agent.

📸 צלם/י n8n — Simple Memory node מחובר ל-Memory port של AI Agent (port שונה מה-Tools port). שלושת ה-nodes גלויים: AI Agent במרכז, Gmail ו-Sheets מתחת, Memory מחובר לצד

לחלופין, לזיכרון חזק יותר שנשמר בין sessions שונות: מוסיפות/ים שורה ל-Google Sheets בסוף כל ריצה עם סיכום קצר של מה נעשה. בתחילת כל ריצה, קריאת 5 השורות האחרונות. זה persistent memory בלי מסד נתונים.

ה-Workflow השלם

כך נראה ה-workflow המוגמר:

[Manual Trigger]
       |
       v
[AI Agent] <-- Tools port: [Gmail] [Google Sheets]
    ^
    |
    Memory port: [Simple Memory]
📸 צלם/י n8n — Workflow מלא עם כל ה-nodes מחוברים: Manual Trigger מחובר ל-AI Agent, Gmail ו-Sheets מחוברים ל-Tools port, Simple Memory מחובר ל-Memory port. תצוגת קנבס מלאה

ריצה ראשונה

לוחצות/ים "Test workflow". n8n מריצה את ה-workflow ומראה את ההתקדמות בזמן אמת.

📸 צלם/י n8n — Workflow רץ: nodes מאירים בירוק אחד אחד בסדר הריצה. AI Agent node מראה "Running" עם אנימציה

לוחצות/ים על ה-AI Agent node אחרי הריצה לראות מה עשה:

📸 צלם/י n8n — AI Agent node output panel: רשימת הצעדים שהאייג׳נט ביצע ("Read Gmail", "Write to Sheets"), תוצאת כל צעד, והפלט הסופי

בעיות נפוצות בריצה הראשונה:

API key לא עובד: חזרו ל-Credentials ב-n8n Settings, ווידאו שה-Anthropic key הועתק נכון בלי רווחים.

Gmail לא מחזיר מיילים: ווידאו שהרשאות ה-Gmail OAuth כוללות קריאת מיילים. לפעמים צריך לאשר מחדש.

האייג׳נט לא עוצר: ה-System Message לא ברור מספיק לגבי מה המשמעות של "סיימתי". הוסיפו: "כשסיימת לעבד את כל המיילים, תחזיר סיכום בפורמט X ותפסיק."
