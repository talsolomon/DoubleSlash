בנה אייג׳נט אחד: חלק ב׳ מתוך שלושה

Claude Desktop, הסטאפ האמיתי שבאמת עובד

בחלק הקודם הבנו מה זה אייג׳נט, למה כלים הם הלב שלו, ולמה קבצים מקומיים הם הזיכרון האמיתי שלו. עכשיו הגיע הזמן לבנות.

אחת הטעויות הכי נפוצות של אנשים שמתחילים לבנות אייג׳נטים: הם פותחים את claude.ai בדפדפן, כותבים פרומפט ארוך, ומגלים שמחר הכל נשכח. זה לא מערכת. זה שיחה.

מה שנבנה בחלק הזה הוא אחר לגמרי: Claude Desktop עם גישה לתיקיית קבצים מקומית. Claude יקרא קבצים, יכתוב קבצים, ויזכור מה שכתבתם/ן כי הזיכרון שלו הוא הדיסק שלכם/ן.

מה אנחנו בונים: התמונה המלאה

לפני שמתחילים שלב אחרי שלב, כדאי לראות לאן אנחנו הולכים.

בסוף החלק הזה יהיה לכם/ן סטאפ כזה:

  • Claude Desktop: האפליקציה שמריצה את ה-AI. יש בה שלוש לשוניות בסיידבר. נעבוד בלשונית Code.
  • Obsidian: תוכנת עריכה חינמית שמציגה את הקבצים שלכם/ן בצורה נוחה. Claude כותב, Obsidian מציג.
  • תיקיית brain: תיקייה מקומית במחשב עם קבצי ה-AI שלכם/ן. identity.md, agents/, memory.md. Claude קורא ומעדכן אותה.
  • MCP: חיבור שמאפשר ל-Claude Desktop לגשת לתיקייה. קובץ הגדרות אחד, העתק-הדבק.

ביחד: Claude שמכיר אתכם/ן, שנמצא במחשב שלכם/ן, שעובד על קבצים אמיתיים, ושזוכר בין ריצות. לא צ׳אט. מערכת.

לשונית Code ב-Claude Desktop: לא "לכתוב קוד". זו הלשונית שמחברת את Claude לתיקיות המחשב שלכם/ן. היא מאפשרת לו לקרוא, לכתוב וליצור קבצים ישר בדיסק.

מה צריך לפני שמתחילים

  • מנוי Claude Pro (20 דולר לחודש). הגרסה החינמית מוגבלת מדי. אם לשונית Code לא זמינה ב-Pro, תצטרכו Max (100 דולר) — Anthropic מגבילים גישה לחלק מהמשתמשים.
  • Obsidian: חינמי לגמרי. obsidian.md
  • Node.js: חינמי, דקה להתקנה. nodejs.org
  • 30 דקות שקטות לסטאפ ראשוני

1 Obsidian: תיקיית הבסיס

Obsidian היא תוכנת הערות חינמית שעובדת עם קבצי markdown רגילים על המחשב שלכם/ן. Claude כותב לקבצים, Obsidian מציג אותם בצורה קריאה. אפשר גם בלי Obsidian לגמרי, אבל זה הרבה יותר נוח איתה.

הולכות/ים ל-obsidian.md, מורידות/ים, מתקינות/ים כרגיל.

📸 צלם/י obsidian.md — עמוד הורדה עם כפתור "Download" לפי מערכת הפעלה

פותחות/ים Obsidian בפעם הראשונה. מוצאות/ים "Create new vault".

📸 צלם/י Obsidian — מסך פתיחה ראשוני עם האפשרות "Create new vault"

שם ה-vault: רק אנגלית, בלי רווחים. לדוגמה: my-brain או tal-workspace.

מיקום: לחצו "Browse" ובחרו Documents. חשוב מאוד: לא iCloud, לא OneDrive, לא Google Drive. תיקייה מסונכרנת לענן גורמת לבעיות כשהמחשב ו-Claude כותבים לאותו קובץ בו-זמנית. רק מחשב מקומי.

📸 צלם/י Obsidian — חלון יצירת vault, שדה "Name" עם שם באנגלית, שדה "Location" מצביע ל-Documents (לא iCloud)

שמרו את הנתיב המלא לתיקייה. תצטרכו אותו בשלב 4. לדוגמה:

Mac:     /Users/yourname/Documents/my-brain
Windows: C:\Users\yourname\Documents\my-brain
עובדה חביבה: Obsidian שומרת הכל כקבצי .md רגילים.
אין נעילה לפלטפורמה, אין פורמט קנייני.
אם מחר תחליטו לעזוב Obsidian, הקבצים נשארים שלכם/ן.

2 Node.js: כלי שקט שעובד מאחורי הקלעים

Node.js היא סביבת ריצה שה-MCP server צריך כדי לתקשר עם Claude. לא צריך ללמוד אותה. צריך רק להתקין.

הולכות/ים ל-nodejs.org. מורידות/ים LTS (הגרסה היציבה, לא Latest).

📸 צלם/י nodejs.org — עמוד ראשי עם שני כפתורים: "LTS" מסומן, "Current" לידו

מתקינות/ים כמו כל תוכנה רגילה. אחרי ההתקנה: פותחות/ים Terminal (Mac: Cmd+Space, כותבות/ים "Terminal") או Command Prompt (Windows: Win+R, כותבות/ים "cmd"), ומקלידות/ים:

node --version

אמורה לצאת גרסה כמו v20.x.x. אם יצאה שגיאה, סגרו את הטרמינל ופתחו מחדש ונסו שוב.

3 Claude Desktop: ולשונית Code

הולכות/ים ל-claude.ai/download. מורידות/ים לפי מערכת ההפעלה.

📸 צלם/י claude.ai/download — עמוד עם כפתורי הורדה ל-Mac ו-Windows

מתקינות/ים ופותחות/ים. מתחברות/ים עם חשבון Claude.ai. אחרי הכניסה, מסתכלות/ים על הסיידבר הימני.

📸 צלם/י Claude Desktop — אחרי כניסה, סיידבר עם שלוש לשוניות: Chat, Cowork, Code

בסיידבר יש שלוש לשוניות: Chat (צ׳אט רגיל), Cowork (בטא), ו-Code. לוחצות/ים על Code.

📸 צלם/י Claude Desktop — לשונית Code פתוחה, ממשק שונה מהצ׳אט הרגיל, שדה בחירת תיקייה גלוי

אם לא רואות/ים את לשונית Code: עדכנו לגרסה האחרונה דרך Claude בתפריט → Check for Updates. אם גם אחרי עדכון לא מופיעה, יתכן שתצטרכו לשדרג למנוי Max.

עובדה חביבה: לשונית Code היא לא "לכתוב Python".
זו הלשונית שמחברת את Claude לתיקיות המחשב שלכם/ן.
השם מבלבל. הפונקציה הכרחית.

4 חיבור MCP: כך Claude יגיע לקבצים שלכם/ן

MCP (Model Context Protocol) הוא החיבור בין Claude Desktop לתיקיות המחשב. מגדירים אותו פעם אחת בקובץ JSON. זה קצת טכני אבל ישר:

ב-Mac, פותחות/ים Finder, לוחצות/ים Cmd+Shift+G, ומדביקות/ים:

~/Library/Application Support/Claude

ב-Windows, לוחצות/ים Win+R, מדביקות/ים:

%APPDATA%\Claude

מחפשות/ים קובץ בשם claude_desktop_config.json. אם לא קיים, צרו אחד. פותחות/ים אותו ב-TextEdit (Mac) או Notepad (Windows).

📸 צלם/י Finder/Explorer — תיקיית Claude פתוחה, קובץ claude_desktop_config.json מסומן

מוחקות/ים את כל התוכן ומדביקות/ים:

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/YOUR_USERNAME/Documents/my-brain"
      ]
    }
  }
}

ב-Windows הנתיב נראה אחרת:

{
  "mcpServers": {
    "filesystem": {
      "command": "npx.cmd",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "C:\\Users\\YOUR_USERNAME\\Documents\\my-brain"
      ]
    }
  }
}

מחליפות/ים YOUR_USERNAME בשם המשתמש/ת שלכם/ן, ו-my-brain בשם ה-vault שבחרתם/ן בשלב 1. שומרות/ים. סוגרות/ים Claude Desktop לגמרי ופותחות/ים מחדש.

📸 צלם/י TextEdit/Notepad — קובץ claude_desktop_config.json פתוח עם ה-JSON מלא, נתיב ה-vault גלוי

5 בדיקה: ניצור קובץ ראשון

ב-Claude Desktop, לוחצות/ים על לשונית Code. בפינה הימנית-תחתונה יש dropdown. ווידאו שבחרתם/ן Local (לא GitHub). לוחצות/ים Select a folder ובוחרות/ים את תיקיית ה-vault.

📸 צלם/י Claude Desktop Code — dropdown מראה "Local" נבחר, כפתור "Select a folder" גלוי

בשדה הצ׳אט, כותבות/ים:

Create a new file called "test.md" with the content "Hello, Claude is connected!"

Claude יבקש אישור לביצוע הפעולה. תנו אישור. אחרי שניות אחדות, פתחו את Obsidian. אמור להיות שם קובץ test.md.

📸 צלם/י Obsidian — קובץ test.md מופיע בסיידבר, התוכן "Hello, Claude is connected!" גלוי בחלון

אם הקובץ לא מופיע: סגרו את Obsidian לגמרי ופתחו מחדש. ב-90% מהמקרים זה פותר. אם לא, ווידאו שהנתיב בקובץ ה-JSON זהה בדיוק לנתיב ה-vault שיצרתם/ן.

6 תיקיית המוח: מבנה שעובד

עכשיו נבנה את מה שהופך את הסטאפ הזה למשהו שעובד כל יום, לא רק בטסט. מבנה התיקיות שנמצא בבסיס של כל מערכת AI אגנטית שעובדת:

my-brain/
  brain/
    identity.md      ← מי אתם/ן
    projects.md      ← מה עובד עכשיו
    memory.md        ← מה האייג׳נט למד
  agents/
    briefing.md      ← הוראות לאייג׳נט הבריפינג
    content.md       ← הוראות לאייג׳נט התוכן

צרו את המבנה הזה: תיקיית brain ותיקיית agents בתוך ה-vault. ניתן לעשות את זה ישירות ב-Obsidian או לבקש מ-Claude ליצור אותן.

📸 צלם/י Obsidian — סיידבר עם המבנה: תיקיות brain/ ו-agents/ גלויות, קבצי .md בתוכן

עכשיו נכתוב את שלושת הקבצים הראשונים. אלה הקבצים שקובעים מה האייג׳נט שלכם/ן יודע.

brain/identity.md — מי אתם/ן:

שמי/שמי [השם שלך].
אני [התפקיד שלך — מנהל מוצר / יועצת / כותב תוכן / וכו׳].
הסגנון שלי: [ישיר / חם / מקצועי / שמור / תכליתי].
אני עובד/ת בעיקר על: [נושאי עבודה עיקריים].
כלים שאני משתמש/ת בהם יום-יום: [Gmail, Notion, Slack, וכו׳].
שפת עבודה: עברית. פורמט פלט מועדף: רשימות קצרות.
מה שאני לא רוצה מ-AI: הסברים מיותרים, מחמאות, "בוודאי!"

brain/projects.md — מה עובד עכשיו:

פרויקטים פעילים כרגע:
- [שם פרויקט]: [מה זה, מה השלב, מה הבלוק]
- [שם פרויקט]: [מה זה, מה השלב, מה הבלוק]

פגישות קרובות:
- [תאריך]: [עם מי, נושא]

החלטות שהתקבלו לאחרונה:
- [תאריך]: [ההחלטה]

brain/memory.md — יתחיל ריק. האייג׳נט יוסיף לכם/ן לאחר כל ריצה מה למד.

7 האייג׳נט הראשון: קובץ ההוראות

עכשיו לכתוב את ה-agents/briefing.md, קובץ ההוראות לאייג׳נט הבריפינג הבוקרי. זה המסמך שאנחנו מביאים לכל שיחה. Claude יקרא אותו וידע בדיוק מה לעשות.

אתה אייג׳נט הבריפינג הבוקרי.

**לפני כל ריצה:** קרא את brain/identity.md ואת brain/projects.md.
**בסוף כל ריצה:** עדכן את brain/memory.md עם מה שגילית היום.

**מה לעשות כשמפעילים אותך:**
1. בקש ממני לשתף את תוכן האימייל או היומן של הבוקר
   (או: אם יש גישה ל-Gmail, קרא 10 מיילים חדשים)
2. לכל פריט: קטגוריה (תשובה נדרשת / לידיעה / לא רלוונטי)
3. סכם בפורמט ברור: "דורש ממני פעולה" ו"לידיעה בלבד"
4. שמור את הסיכום ב-brain/memory.md עם תאריך

**מה שאתה לא עושה:**
- לא שולח שום דבר
- לא מוחק כלום
- לא ניגש לקבצים מחוץ ל-brain/ ו-agents/
- אם משהו לא ברור, שואל לפני שפועל

**פורמט פלט:**
קצר. עברית. רשימות. בלי מחמאות.
📸 צלם/י Obsidian — agents/briefing.md פתוח עם ההוראות, פורמט markdown גלוי

8 שיחה ראשונה עם האייג׳נט

חוזרות/ים ל-Claude Desktop, לשונית Code. ווידאו שה-vault שלכם/ן עדיין נבחר (פינה ימנית-תחתונה).

כותבות/ים:

Read agents/briefing.md and brain/identity.md, then introduce yourself based on those instructions.
📸 צלם/י Claude Desktop Code — Claude קורא את הקבצים ומציג תוצאה: "קראתי את ההוראות. אני אייג׳נט הבריפינג..."

Claude קרא את הקבצים שכתבתם/ן, הבין מי אתם/ן ומה הוא עושה, והציג את עצמו בהתאם. זה לא "פרומפט חכם". זה AI שמכיר אתכם/ן כי כתבתם/ן לו את עצמו.

עכשיו תוכלו לכתוב:

Here are my emails from this morning: [הדביקו תוכן מאימייל]

בדקו ב-Obsidian: אמורה להיות עכשיו כניסה חדשה ב-brain/memory.md עם תאריך וסיכום הריצה.

מה Claude Desktop יכול לעשות עכשיו

עם הסטאפ הזה ברשותכם/ן:

  • לקרוא ולכתוב קבצים מהתיקיות שהגדרתם/ן
  • לזכור בין שיחות דרך קבצי brain/
  • לעקוב אחר פרויקטים דרך brain/projects.md שמתעדכן
  • לכתוב בסגנון שלכם/ן כי קרא את identity.md
  • להפעיל אייג׳נטים שונים לפי קבצי agents/ שונים
  • לחפש בקבצים: "חפש בכל הקבצים שלי משהו על לקוח X"
📸 צלם/י Claude Desktop Code — שיחה שבה Claude קורא קבצים ומציג תוצאה: "מצאתי את הדברים הבאים הקשורים ל..."

מה Claude Desktop עדיין לא יכול: להפעיל את עצמו אוטומטית. הוא מחכה לכם/ן לפתוח שיחה ולבקש. אין trigger בלוח זמנים, אין "כל בוקר ב-8:00". לאוטומציה שרצה לבד בלי שתהיו שם, נצטרך את חלק ג׳.
