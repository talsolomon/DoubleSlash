# Project Plan — Consulting Sprint
_Updated: 2026-05-27_

---

## Goal
$12,000 closed within 7–10 days. One sprint, one client.

## Milestones

### M1 — First Contact (Day 1)
- [ ] Build prospect list: 15 companies from Crunchbase + Product Hunt
- [ ] Send 10 cold emails (personalized, specific observation per company)
- [ ] LinkedIn outreach to same contacts
- [ ] Target: 2 discovery calls booked

### M2 — First Call (Day 2–3)
- [ ] Run discovery call using script (planning/strategy.md §4)
- [ ] Surface budget + urgency in first 10 minutes
- [ ] Close on the call or follow up within 24h

### M3 — First Close (Day 3–7)
- [ ] Send one-page agreement + 50% invoice
- [ ] Confirm sprint start date
- [ ] Lock deliverables scope

### M4 — Sprint Execution (Week 2)
- [ ] UX audit (heuristic + analytics review)
- [ ] Flow mapping
- [ ] 3–5 screen redesigns in Figma
- [ ] Written findings report

### M5 — Delivery + Collect
- [ ] Live walkthrough session
- [ ] Deliver Figma file + report
- [ ] Collect second 50% payment
- [ ] Ask for referral / testimonial

## Open Decisions
- Pricing ceiling: $12k entry or go to $18k for Series A?
- Payment tool: Stripe invoice or another?
- Case studies: assemble 2–3 from past work before outreach
