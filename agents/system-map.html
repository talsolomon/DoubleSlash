Self-Improvement Loop · All Agents

📈 How agents improve over time

After any correction from Tal → update {agent}-lessons.md in planning/knowledge/.
Rule format: Rule [N]: what to do. Why: what went wrong. When: trigger condition.
Review lessons at next activation. If a lesson contradicts current SKILL.md behavior — the lesson wins until Tal resets it.
Apex runs LS (Lessons Sync) every Monday to pull cross-agent patterns into the shared graph.
